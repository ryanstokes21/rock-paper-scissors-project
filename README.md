# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript as part of The Odin Project Foundations curriculum.

Overview

This project began as a console application and was later refactored into an interactive browser game using the DOM. Players compete against a computer opponent by clicking one of three buttons: Rock, Paper, or Scissors.

The game keeps track of the score in real time and ends when either the player or the computer reaches 5 points.

Features
Play using on-screen buttons
Random computer opponent
Live score tracking
Round result displayed after each selection
Game ends automatically when a player reaches 5 points
Prevents additional rounds after the game is over

What I Learned

This project helped reinforce core JavaScript fundamentals while introducing DOM manipulation and event-driven programming. One of the biggest lessons was breaking the application into smaller, reusable functions instead of writing all of the logic in a single function.

I also gained experience with:

Selecting DOM elements
Responding to user interactions with event listeners
Updating the UI dynamically
Managing application state with variables
Refactoring code to improve readability and maintainability
